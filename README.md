# FUTURE_UIUX_03
📌 Project Title

CRM Dashboard UI for Digital Marketing Agency

📖 Project Description

This project is a web-based CRM (Customer Relationship Management) dashboard designed for a digital marketing agency with a 5-member team managing around 30–40 active clients and handling 15–20 new leads per month.

The goal of this project is to streamline lead tracking, client management, and task coordination in a single centralized platform. Many small agencies rely on spreadsheets and messaging tools, which leads to scattered data, missed follow-ups, and inefficient workflows.

This CRM dashboard solves that problem by providing a structured and scalable interface for managing the entire client lifecycle.

🎯 Key Features
Lead Pipeline with status-based stages (New, Contacted, Proposal Sent, Converted)
Client List with searchable and filterable table
Client Profile with tasks, activity timeline, and notes
Task & Follow-up system with due dates and status tracking
Clean and scalable dashboard layout for daily agency use
🔄 Workflow

The system is designed around a real agency workflow:

Lead → Contacted → Proposal → Converted → Active Client → Tasks & Follow-ups

This ensures smooth transition from lead acquisition to client management and execution.

🧠 Design Approach
Focused on B2B SaaS UX principles
Prioritized clarity, scalability, and usability
Used Kanban layout for lead tracking
Used table-based structure for managing large client data
Designed for quick decision-making and daily usage
🛠 Tools Used
Figma (for UI design)
🚀 Outcome

This project demonstrates the ability to design real-world SaaS dashboards by focusing on workflows instead of just visual design. It helps agencies reduce confusion, improve team coordination, and manage clients efficiently.
